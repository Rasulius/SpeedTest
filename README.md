# Замер скорости интернета

Консольный скрипт на Python для измерения скорости скачивания по указанному URL.  
Дополнительно в проекте есть простой Node.js-сервер для локального тестирования и PowerShell-скрипт для быстрого запуска.

## Состав проекта

- `speed_test.py` — основной Python-скрипт замера скорости.
- `server.js` — тестовый HTTP-сервер (Node.js), отдаёт данные заданного размера.
- `start.ps1` — PowerShell-скрипт: запускает тестовый сервер, выполняет замер и сохраняет лог.

## Требования

- Python 3.8+
- Node.js (только для локального тестирования через `server.js` / `start.ps1`)

Внешние Python-зависимости не используются (только стандартная библиотека).

## Использование `speed_test.py`

Скрипт принимает URL, выполняет запросы последовательно, полностью дочитывает ответ на каждый запрос, считает среднее время, общий объём скачанных данных и скорость.

```bash
python speed_test.py <URL> [-n COUNT] [--timeout SECONDS]
```

Параметры:
- `URL` — адрес ресурса для скачивания (например, ссылка на файл/картинку).
- `-n`, `--num-requests` — количество последовательных запросов (по умолчанию: `10`).
- `--timeout` — таймаут одного запроса в секундах (по умолчанию: `30`).

Пример:

```bash
python speed_test.py https://speed.hetzner.de/100MB.bin -n 10
```

## Единицы измерения

- **Среднее время запроса** — секунды (`с`).
- **Общий объём скачанных данных** — байты (`байт`) и мегабайты (`МБ`).
- **Скорость скачивания** — мегабайты в секунду (`МБ/с`) и мегабиты в секунду (`Мбит/с`).

Скорость рассчитывается по общему объёму скачанных данных и общему времени успешных запросов:
- `МБ/с = байты / (секунды * 1 000 000)`
- `Мбит/с = (байты * 8) / (секунды * 1 000 000)` (десятичные мегабиты, 1 Мбит = 1 000 000 бит)

## Локальное тестирование (Node.js)

Запуск тестового сервера вручную:

```bash
node server.js
```

По умолчанию: `http://localhost:3000/`, размер ответа `5 MB`.

Настройка через переменные окружения:

```powershell
$env:PORT=3000; $env:SIZE_MB=10; node server.js
```

```bash
PORT=3000 SIZE_MB=10 node server.js
```

Затем запуск замера:

```bash
python speed_test.py http://localhost:3000/ -n 10
```

## Быстрый запуск через PowerShell

`start.ps1` автоматически поднимает `server.js`, выполняет `speed_test.py` и сохраняет лог скорости.

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

С параметрами:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1 -Port 3000 -SizeMB 5 -Count 10 -LogPath speed-log.txt
```

Параметры:
- `-Port` — порт тестового сервера (по умолчанию `3000`)
- `-SizeMB` — размер тестовых данных в МБ (по умолчанию `5`)
- `-Count` — количество запросов (по умолчанию `10`)
- `-LogPath` — файл лога скорости (по умолчанию `speed-log.txt`)
